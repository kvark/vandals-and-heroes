# Vandals and Heroes — design north star

**Original vehicular combat RPG set in the Vangers universe.**

Sibling to [`vange-rs`](https://github.com/kvark/vange-rs) (the 1998 remake), not a clone of the original game.

Steer toward:

- Car-as-character
- Wasteland lore
- Heroes vs vandals

Shared GameDev baseline (stacks + north stars table): [`docs/gamedev-baseline.md`](./gamedev-baseline.md). Living notes: https://hackmd.io/s/HkMqq2btze
